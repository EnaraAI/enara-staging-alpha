ENARA staging repo: how it fits together

EnaraAI/enara-staging-alpha · one Vercel project per site: a React app + one Node API function · 21 Nov 2026
Who uses it

Students (13+)

Web app: courses, assignments, AI tutor chat, live avatar call, speaking exams

Children (under 13)

Kids app: tutor with picture choices (292 own pictures), microphone, "Talk live"

Teachers & school admins

Curriculum, assessments, grading, classes, analytics, parent codes

Parents

Parents portal: progress, activity, controls (phone + desktop layout)

Moodle (school LMS)

Opens ENARA through LTI 1.3: launch, activity picker, grades back, roster

▼ browser / LTI launch

frontend/ (React + Vite, served as static files)

pages/ staff and student screens · kids/ kids app + public/kids/pics · parents/ parents portal · components/enara/LiveAvatarModal live avatar (Anam SDK) · services/apiService.ts calls the API

▼ /api (vercel.json → api/index.js, max 60 s)

backend/ (Node + Express, TypeScript)

routes/ → controllers/

32 route files: auth, me (student), tutor, avatar, assessments, grading, curriculum, learning, analytics, usage, uploads…

models/ (65, MongoDB)

users, students, classes, curriculums, assessments, attempts, TutorSession, AvatarSession, errors-to-work-on, UsageLedger, AiCall…

integrations/lms/

LTI 1.3 adapter; core: launch, deep linking, grades (AGS) with outbox, roster (NRPS), grade ledger

parents/ · email/ · auth/

parent codes & sign-in, approved emails (test inbox on lms-test), JWT auth, roles

Tutor engine (services/, the Tutor track)

languageTeachingContext.ts builds the prompt (lesson, learner, age, review lines) · languageTurnPipeline.ts one turn: prepare → model → guards (child trim, one task) → grade marker · engineV2.ts named switches from ENARA_ENGINE_V2 (planner2, spacedReview, reviewFirst, childRule, realChat, kidsAudioVisual, avatarSpeaking, kidsSpeaking…) · errorsToWorkOn.ts spaced and adaptive review · kidsPictures.ts · avatarSpeaking.ts

maintenance/ (lms-test only)

migrations, seed, mock LMS + deploy health check, avatar-usage readout. 404 elsewhere; needs a token

config/ · middleware/

env + switches, AI pause and spend cap, rate limits, staging guard

branch claude/tutor-* · lms-* · parents-*→PR into lms-test-live→lms-e2e: Moodle 4.5 + Playwright, 18 scenarios (e2e/)→guard: enara-lms-test only→merge→switches from deploy/lms-test.flags.json→vercel deploy→migrations→health check (mock LMS)→lms-test.enara.app live · rollback on failure
