## Shot list: style details
- **Transitions:** smooth slide and morph between scenes, 400–600 ms easing, with one camera-like push per scene.
- **Type:** a clean sans-serif (Inter, an open licence). Key lines are animated word by word.
- **Icons and UI:** drawn by us in code (rounded cards, soft shadows); no screenshots.
- **Kids pictures:** our own drawn set only.
- **Logos:** no logos except a text badge "Works with Moodle".

## How I'll make it (no product code touched, nothing deployed)
- **Animation:** our own HTML/CSS/JS scenes, rendered frame by frame with a headless browser and ffmpeg. All code is ours, so there are no licence fees (Remotion needs a paid company licence, so I won't use it).
- **Narration:** an open text-to-speech voice whose licence allows commercial use. I'll name the voice and its licence in the report.
- **Music:** composed in code by me (soft ambient pads), so it's ours, with no licence risk.
- **Subtitles:** English (from the script) and Arabic (my translation), as `.srt` files, and burned into the vertical cut.
- **Outputs:**
  - `enara-school-film-16x9.mp4` (1080p);
  - `enara-social-9x16.mp4` (60 s);
  - `subtitles-en.srt` and `subtitles-ar.srt`;
  - a 3-line report.
