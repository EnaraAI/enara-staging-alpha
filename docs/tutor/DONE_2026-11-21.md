## #63: adopted from ARCHITECTURE.md, for a tutor that teaches every subject
| Switch | What it does |
|---|---|
| `modelFallback` | Retry backoff. A fallback key or model on 401/429/5xx. A real key check on `/ready`. An ALERT on a deploy when a key is rejected. |
| `gradeAllSubjects` | Practice answers in **every** subject feed the learner memory (right/wrong, session summaries, spaced review). |
| `ragRewrite`, `ragReuse` | An Arabic question can find English material (one keyword rewrite). "Explain again" reuses the last passages. |
| `groundedRefusal` | "This isn't in your course materials." The turn is flagged for teachers. |
| `topicMemory` | The "last time" line names the material used and the questions the materials did not cover. |
| (test set) | 60 fake questions for maths, science and Arabic. Retrieval is scored in CI. |
| `methodFromEvidence` | The planner uses the teaching method this learner clearly succeeded after. |
| `repairOnce` | One regenerate when the hidden grading line is missing. |
| `injectionCheck` | Text that tries to change the tutor's instructions is neutralised (in learner messages and passages). |
