## Relevant but excluded (no per-answer Claude scores, or not learner answers)
- **LAILA (AR essays):** `backend/src/scripts/candidateV2LailaPilot.ts` (claude-sonnet-5-5, 100 essays), `hybridLailaEval.ts` / `hybridLailaR1Eval.ts`, `services/candidateV2/*`. Only the code is in git; outputs and LAILA data are git-ignored. No result files appear on any branch or in history. `hybridV1` golden fixtures hold 11 gold anchors, no Claude outputs.
- **AES / ELLIPSE / LAILA baselines and training** (`tutor-lms-aes-*`, `tutor-lms-ellipse-results`, `tutor-lms-recal-results`, `ESSAY_SCORING_*`): 22–23 Nov. They use the DeepSeek engine or trained models, keep numbers only, and store no essay text.
- **Assessment bench** `data/assessment-bench/*` (1,080 answers, EN/AR): gold is "author (provisional)", written by the Claude engineering agent together with the answers. That is not blind grading. DeepSeek graded these (run p3-v2), but only summary numbers are kept (`baseline.json`). The answers that overlap with Mishkat already have blind Opus/Sonnet marks (#6).
- **Language-teaching benchmarks** `docs/benchmarks/language-teaching/2026110*/–1112*/…/judge_v2_*.jsonl` (Haiku/Sonnet/Opus judges, 9–13 Nov): these rate **tutor replies** on ltb-rubric-v2, including an `answer_judgement` criterion. They do not score learner answers.
- **LO experiment** (`…/20261113-lo-experiment/lo_assessment*.jsonl`): scored with a deterministic key. Haiku played the learner.
- **ESL2–ESL6 judges** (`agent_sim_esl{2..6}/judge`, `validation/judgeA|B`): these code learning-rule events on **tutor turns**. Post-tests were rule-scored (ESL6 `ASSESS_pre`: 10,152 answers, all exact/rule).
- **Tutor in-turn verdicts (Claude agents as tutor):** ESL7 `sessions/` has about 2,880 `[[assess verdict]]` on learner messages (1,583 CORRECT, 356 INCORRECT, 313 PARTIAL…). ESL6/ESL2–5 sessions have the same kind. These are categorical tutor judgements, not extracted. Mine them only if turn-level grading is wanted.
- **Clarity / agent_sim_18 / fixes:** ratings of tutor explanations. The clarity post-test is stored only as per-learner accuracy, without answers.
- **DeepSeek match 100-turn** (`deploy/lms-test/dsmatch/turns.json`, `tutor-lms-dscompare-results`): DeepSeek only. The expected verdicts were hand-written.
- `research/assessment-review/a1a2`: agent reviews of **items** (CEFR fit), not answers. `GRADER_DET*` / `GRADER_CURRENT|FIXED`: deterministic graderV2 code, not Claude.
- `grader-round8` ESL6 judge rounds, `docs/staging` P19 leak guard, P12/F3B diagnostics: not answer grading.
- All local checkouts (enara-staging-alpha, lmsint, copykeys, esl-methods, esl7, litplan, kidspack, avatarcost, mishkat, mkt, planner2, reviewpack, rulesfirst) are clean. There are no untracked result files.
