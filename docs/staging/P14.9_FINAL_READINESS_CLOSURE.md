## 7. Local changes made

| File | Change | Why |
|---|---|---|
| `backend/test/p14_9TenantIsolation.test.ts` (new) | Seeds two full synthetic schools with the repository's `seed4Level1` in an in-memory database, plus class 2 in school A (own batch, teacher and student). Runs every API route as six school-A identities with school B's **real** ids, and GETs with `?origin=all`. Asserts no school-B data in any 2xx response (an exact echo of the requested id is ignored; a returned record still carries `institutionId`); school B's stored records unchanged after all write attempts (sha-256 digest); no 5xx except `*_UNAVAILABLE`; class boundaries both ways; explicit roster/profile/content probes; **0 outbound network calls** (all non-loopback `fetch` blocked) | G6b and G7 local evidence with real ids (the P7 sweep used a placeholder id) |

**No production code changed in this phase.** Investigation results:
- **Class "leak" during the first run:** a fixture error, not a defect. Enrollment is **batch-based by design** (`studentCourseService.getEnrolledInstances`: `studentIds` **or** `batchId`), so every student of a batch is in every class on that batch. Class 2 was first placed on class 1's batch; it now has its own batch. **Policy fact for the owner:** a teacher of any class on a batch can see all of that batch's students.
- **`/api/me/analytics/subjects/:name` "leak":** an echo. The handler reads only the caller's own student record and repeats the name it was given.
- **Mutation check:** removing the school filter in `learningAccess.resolveStudentForRead` made the test fail (school A's admin read a school-B profile). The file was then restored from git and is identical to HEAD.

## 12. Proposed emergency-stop rehearsal (not executed)

At near-zero spend, as step 1 of the window:
1. Make one minimal non-grading call (for example, one short Educator AI Chat question by the synthetic teacher).
2. Verify one `usage_ledger` row, the `test_spend:<id>` counter (Atlas, read-only) and the provider console usage.
3. **Stop A, key disable:** disable the key in the Anthropic console, then make the same call → it must fail with no provider usage. Re-enable afterwards.
4. **Stop B, rollback:** see §13.

**Coverage:**
- **Key disable and rollback** stop every feature including grading.
- **`AI_PAUSED` and the global/school pause stop non-grading only.** By the P0d design, grading continues during a pause, so a pause is **not** a grading stop.
- **The app cap** stops everything automatically once reached.
