# SIMULATION ONLY

# ESL stage 2: rule-based learner simulation

No real learners took part. Every learner is a scripted knowledge state. Every tutor turn was written by an agent. Learning was scored by blind judge agents that applied fixed rules from second-language research (`config/agent_sim_esl2/LEARNING_RULES.md`). No API was called. These results say how the tutor designs behave against that rule set. They do not say how real students learn.

## Design (reduced, as chosen)

- **Learners:** 36. There are 12 each at A1, A2 and B2. The first language is Arabic. The forms are articles, copula and third-person -s.
- **Learner state:**
  - Beliefs W1 and W2 (wrong) and C1 and C2 (correct), each with a strength from 0 to 3.
  - Errors are seeded from the first language.
  - Start: A1/A2 learners have a summed wrong strength of 3.5. B2 learners start at 0.
- **Arms:**
  - P: plain tutor.
  - A0: ENARA baseline with the plan.
  - A0+LE: adds `levelExplicit`.
  - A0+LE+M: adds the memory emulation.
- **Sessions:** 2 sessions of 5 turns each. Session 2 is a new chat on a later day. There was 1 replication, giving 144 sessions and 1,440 tutor turns.
- **How learning was scored:** a judge agent saw only the knowledge state and the tutor turn, never the arm. It returned rule events. A script then applied rules R1–R7 and generated the learner's next reply.
- **Post-test:** generated by a seeded script; no agent answered it. It had 4 controlled items and 2 free items per learner. It also counted wrong beliefs at strength 0.
- **Statistics:**
  - Paired learner-level differences.
  - 95% bootstrap intervals (10,000 resamples).
  - Exact sign-flip p-values.
  - Holm correction across the 4 contrasts in each outcome and population.
  - Populations: all 36 learners, and the 24 explicit-first (A1/A2) learners.
- **Required fixes before the `levelExplicit` runs** (production code, commit `39c1801`):
  - The rule line is now shown on the first explanation turn.
  - Hint level 2 asks for a new contrast pair.
  - The two-asks detector no longer counts "say the rule in your own words".

## Answers

**Did any ENARA arm beat P above zero after Holm?**

No. On controlled accuracy, both A0+LE and A0+LE+M beat P by +0.11 for all learners and +0.17 for explicit-first learners. All four of those uncorrected bootstrap intervals exclude zero. After Holm, though, p is 0.063 and 0.094, which is not below 0.05. On free production and on wrong beliefs reaching 0, every interval includes zero. `levelExplicit` versus A0 and memory versus `levelExplicit` show no difference whose interval excludes zero. None of this is reported as a win.

**Validation:** all checks passed.
- The scripted order was d > c > b ≈ a.
- Judge agreement was 88%, against a target of at least 85%.
- Noise between repeated runs of the same tutor was small, at most 0.056.

**Limits:**
- Simulation only. Learning follows a hand-written rule set, so the result can only be as good as those rules.
- There was one replication, and n = 36 (24 explicit-first) gives low power. The reduced design was the user's choice.
- The judges are agents. Agreement was 88%, so roughly 1 in 8 judgements is disputable.
- Several judge agents made their own calls on unclear cases (which belief gets credit, and whether a retry counts as independent production).
- Tutor turns were written by agents imitating each arm's prompt and engine output, not by the production model.
- Memory had little to carry: there are no error codes for articles or copula, and beliefs need the `belief` marker.
- A Plain tutor reply said "Good try!" to correct answers in 5 sessions. Those turns were left as written.
- The post-test has 6 items per learner, so scores are coarse.
- B2 learners start at ceiling and add no signal.
