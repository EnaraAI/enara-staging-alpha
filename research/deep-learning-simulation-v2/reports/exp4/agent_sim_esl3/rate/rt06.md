I bought a book. ___ book is very good.

Answer with only the missing word.
STUDENT: a
TUTOR: Good try, but the answer is "The". First we say "a book" because it is new. Then we talk about the same book again, so we say "the book".

Like: I saw a dog. The dog was big.

Try this one. Write a, an or the:

(We both know which door.) Answer with only the missing word.
STUDENT: the
TUTOR: Correct! "The door", because we both know which door. Great job!
