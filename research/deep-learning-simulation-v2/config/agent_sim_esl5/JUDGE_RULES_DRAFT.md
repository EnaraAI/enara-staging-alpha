# SIMULATION ONLY
EXPLORATORY DRAFT — not used by any study yet

Proposed clearer judge rules, from 71 judge disagreements among the 165 ESL4 recheck cases (rounds 3 and 7) (counts are in the scratchpad step5_result.md). The frozen ESL2/ESL4 files are unchanged. No disagreement involved R2 or R7, so those rules stay as they are.

## A. Which correct belief to credit (24 cases)
**Proposed wording.** Before you judge, map the item to the belief or beliefs it *tests*. A belief is tested only if one of its wrong counterparts could change the answer:
- articles: C1 = an article is present before a singular countable noun; C2 = the choice between a and an. A blank "a or an" with the noun given tests C2 only. A blank where leaving it empty is possible tests C1 and C2. An item about "the" versus "a" (first or second mention) tests neither, so it gets no R3 or R4.
- copula: a blank "am/is/are" with the gap marked tests C2 only (W1's omission is not offered). A free sentence tests C1 and C2.
- 3rd -s: a he/she/it verb with a plain stem tests C1. A stem ending in sh/ch/s/x/o/consonant+y, or an I/you/we/they subject, tests C2. A he/she/it subject with an -es stem tests both.
Credit R3/R4 to every tested belief and to no others. Use the next_task "probes" list as the same mapping.

**Worked example.** Previous turn: "Write a or an: My uncle is ___ doctor." Learner: "a" (correct). Tutor: "Yes, 'a' is correct." Events: R3 C2 (and R4 C2 if the item is new). Why: the options were a/an, so W1 (omitting) could not show. Only C2 was tested.

## B. R4: what counts as a new item (14 cases + 7 mixed)
**Proposed wording.** R4 applies only if all of these hold: (1) the learner's correct answer is to an item they have not answered before in this session. A retry of the same sentence after feedback is NOT new. (2) The previous tutor turn did not give the answer, a completed model of the same sentence, or a hint that settles which word goes there (e.g. "I goes with am"). A rule stated in general terms with a *different* example sentence does not block R4. (3) The item tests the belief (see A). R4 is judged from the previous tutor turn and the learner's message only, never from the praise in the current turn.

**Worked example.** Previous turn: "Right: We are tall. Wrong: We is tall. ... Then try again: I ___ a student." Learner: "am". Tutor: "Yes, 'am' is right now." Events: R3 C2 only. Why: it is a retry of an item the learner already got wrong, so it is not new. Counter-example: previous turn "Write a or an: He wants ___ umbrella." (a fresh item, no hint). Learner: "an". Tutor confirms. Events: R3 C2 and R4 C2.

## C. R1 from an item explanation, or for a belief at 0 (16 cases + 12 mixed)
**Proposed wording.** R1 needs a general rule (it names a class: "he/she/it", "verbs ending in -ch", "a vowel sound") that is correct and that, if the learner believed it, would rule out Wk's error. A sentence that only justifies this one answer ("Ali is he, so reads") counts if, and only if, it contains such a general clause ("he/she/it takes -s"). A pure restatement of the item ("'washes' is correct") does not count. Report R1 even when Wk is already 0 (the script clamps at 0), so both judges agree. Do not report R1 for a belief whose error the turn's rule does not address.

**Worked example.** State W1 = 0. Learner wrote "He drinks" (correct). Tutor: "Yes! 'He' is one person, so the verb takes -s." Events: R3 C1, R1 W1 (no change, already 0). Why: "one person ... the verb takes -s" is a general he/she/it rule that contradicts W1. If the tutor wrote only "Yes, 'drinks' is right", there is no R1.

## D. Hint-like or vague lines (5 cases)
**Proposed wording.** A line labelled "The rule:" is not enough. R1 needs the form named in words (am/is/are, a/an, -s/-es). "The gap always needs one word", "look at the first word" and "that word changes" are hints, so they get no R1. A bare "we cannot say X" with no right form and no rule is not R1 either. If it has a right/wrong pair, judge it under R2.

**Worked example.** Learner left the gap empty (W1 error). Tutor: "The rule: this gap always needs one word. Try again: I ___ a student." Events: none (R5/R6 not needed). Why: the line does not name am/is/are or say when they are used, so it is a hint. If the tutor instead wrote "Every present sentence needs am, is or are: She is a teacher", the events are R1 W1.
