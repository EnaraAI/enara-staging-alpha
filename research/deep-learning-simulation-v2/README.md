# ENARA Deep Learning Simulation v2.0

AI-only educational research platform to evaluate ENARA AI Tutor with simulated students. **Not evidence of real-human learning.**

Docs: `docs/ARCHITECTURE.md` · `docs/RESEARCH_PROTOCOL.md` · `docs/SIMULATOR.md` · `docs/STATISTICS.md` · `docs/EXECUTION_GUIDE.md` · `docs/VALIDATION_REPORT.md` (results and the final implementation report) · `config/preregistration.json`.
Benchmark: `benchmark/outcomes/*.json` (48 outcomes: 8 each of grammar, vocabulary, reading, writing, functional language, text-based listening/dialogue comprehension).
Sample complete experiment report: `runs/validation-campaign-1/reports/` (generated only from recorded results).
